# Study Time Statistics（学习时间统计）

[English](README.md)

Study Time Statistics 帮你看清时间花在了哪些 Obsidian 笔记上：自动记录笔记与 PDF 的阅读时间、打开次数，在 Markdown 笔记顶部显示统计条，并把本地记录整理成趋势、排行榜和按文件夹浏览的投入地图。你还可以自行记录每次读了多少内容。插件不会把统计数据写进笔记正文。

**以下介绍以 2.6.0 版为准。** 尚在开发的功能不会冒充本版功能；后续方向见 [版本路线](ROADMAP.md)。

![从 Obsidian 实际界面截取的学习分析总览，已排除私人笔记信息](assets/analytics-overview-2026-10-02.png)

*2026-10-02 从 Obsidian 中运行的 3.0.0 开发版直接裁切，部分控件可能与 2.6.0 版不同。这不是概念图；截图只显示汇总统计，没有笔记标题、路径、文件夹或正文。*

## 能做什么

| 在 Obsidian 的位置 | 可以查看或操作的内容 |
| --- | --- |
| Markdown 笔记顶部 | 打开次数、累计和平均阅读时间、最长单次、活跃天数、当前连续天数、最近阅读时间。统计条随正文滚动，不修改文件。 |
| 学习总览 | 今日与本周投入、目标进度、周环比、会话质量、高投入时段和最近未打开的笔记。 |
| 统计分析 | 趋势与热力图、五类排行榜、本地筛选及周期对比、按文件夹浏览的投入地图。 |
| 阅读记录 | 检查和修正会话；可选记录阅读覆盖度、位置与字符；设置日、周目标。 |
| 更多 | 生成本地报告、检查数据健康、打开反馈入口。创建和恢复备份的命令在命令面板中。 |

### 自动计时与单篇统计

- 阅读 Markdown 笔记或 PDF 时记录时间和打开次数；状态栏也会显示当前文件的累计阅读时间。默认启用的“严格模式”会在 Obsidian 失去焦点时暂停计时。2.5.0 起还可设置空闲暂停时间（默认 20 分钟，设为 0 可关闭）；这些设置都不能判断你是否理解了内容。
- Markdown 笔记顶部的统计条属于编辑/预览界面，不属于笔记原文；下翻时它也会消失。开启可选的阅读覆盖度后，还能显示覆盖度、阅读位置和已读字符。
- 打开次数与阅读会话分别记录。会话可查看开始时间、时长和对应笔记；漏记或不准确时，可以手动补记、修改或删除。

### 趋势、对比与投入地图

- 按日、周、月、年或全部时间看统计；查看过去 365 天的阅读时长热力图、近 30 天时长与会话图、24 小时与星期分布、单次时长分布、文件夹汇总和最近会话。图表默认跟随 Obsidian 主题色，也可自选颜色；只有热力图用深浅表示强弱，其他图表由柱高或条长表示大小。
- 五类排行榜分别按打开次数、累计阅读、平均每次、最长单次和活跃天数排序。它们只比较**你自己库内的笔记**，不是与其他用户竞争。
- “分析筛选”可按日期、文件夹和笔记名称筛选会话，与等长的上一周期比较，并从结果打开原笔记。
- “学习投入分布”可按时长、打开次数、阅读覆盖或最近阅读浏览整个库，未读的 Markdown/PDF 也在其中；点进文件夹可逐层查看。连续阅读关系只统计两个不重叠、相隔不超过 30 分钟的会话，不推断笔记主题或学习成果。

### 可选的阅读记录与目标

- 开启“阅读覆盖度”后，可给每次阅读填写一个百分比，也可填写阅读起止位置和实际阅读字符；字符数留空时会明确标记估算值。你可以查看记录历史、单篇与文件夹覆盖汇总、365 天覆盖热力图、时段分布、重复阅读量、等效通读遍数和每千字用时。
- 可设置完全本地的日目标与周目标，查看 28 天达标趋势，并人工复核异常长或有歧义的会话。本地交互信号会把新会话标记为“持续交互”“静默学习”“需确认”或“未分类”；标签只是复核线索，不是注意力证明，插件不会悄悄删除有歧义的记录。

### 数据与外观控制

- 数据只存在你的库中：不需要插件账号，没有遥测、广告或自动上传。仪表盘的“反馈与建议”只会在你主动选择时打开 GitHub 表单。
- 在“更多 → 报告导出”中选择日期范围，即可预览本地汇总，并下载 JSON、CSV、Markdown 或复制 Markdown 报告。默认隐藏笔记名称；只有确实需要在导出文件中保留真实路径时才关闭此选项。即使隐藏名称，导出文件仍可能包含私人学习时段与时长。
- 仪表盘及筛选、地图、表格在较窄的屏幕上会调整布局；触摸与页面可见性信号也帮助计时器适应移动端及多窗口使用。
- 可以通过命令面板创建带时间戳的本地备份、恢复最近一份可用备份；“更多”里的“数据健康”会检查重复或无效会话、失效的笔记引用。安全修复前先备份；暂时找不到笔记时保留历史而不自动删除。重命名笔记时，相关记录会迁移到新路径；备份会自动保留最近 20 份。

## 怎样理解这些数字

- **打开次数**：插件观察到笔记成为当前笔记的次数。**平均每次**＝该笔记累计计时时长 ÷ 打开次数，不是“已完成会话时长的平均数”。
- **阅读时长**：笔记处于活动状态时记录的时间，受窗口焦点设置和计时上限影响。静默学习和放着不动可能看起来相似；遇到可疑会话，可以人工复核或修正，别把计时器当成注意力检测器。
- **阅读覆盖度**：你自行填报的各次百分比相加，单篇最多显示 100%。它不测试理解、记忆或掌握。不同字符覆盖量与阅读节奏根据填写记录和字符数估算，不是实际“信息吸收量”。
- **建议回看**：只表示某篇笔记最近没有打开，不预测你是否遗忘。

## 打开仪表盘

点击左侧边栏的柱状图图标，或者打开命令面板运行 **打开学习时间统计**。先看“学习总览”，需要深入时再进入“统计分析、阅读记录、更多”。“阅读覆盖度”默认关闭，可在对应页面或插件设置中开启。

## 安装

### 社区插件市场

插件已收录到 Obsidian 社区插件目录。打开 **设置 → 第三方插件 → 浏览**，搜索 **Study Time Statistics** 即可安装。

[在 Obsidian 插件目录中查看 Study Time Statistics](https://obsidian.md/plugins?id=study-time-statistics)

### 手动安装

1. 从最新 GitHub Release 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 新建 `<你的库>/.obsidian/plugins/study-time-statistics/`。
3. 将三个文件复制到该目录。
4. 重启 Obsidian，然后在 **设置 → 第三方插件** 中启用 **Study Time Statistics**。

## 隐私与数据位置

主要统计保存在你自己的库内，具体为 `.obsidian/plugins/study-time-statistics/data.json`。插件会存储绘图所需的笔记路径与本地学习指标。开启阅读覆盖度后，还会保存你填写的百分比、可选起止位置、手填或估算的阅读字符数、当时的笔记字符数、对应有效时长，以及本地交互次数和时间戳，但绝不保存笔记正文。带时间戳的备份另外保存在库内的 `Study Time Statistics Backups/`，因此备份也包含相同的私人笔记路径和统计数据。插件不会自动通过网络发送数据。本仓库的公开图片使用经许可的真实汇总数值快照，但没有出现真实笔记标题、路径、文件夹或正文。

### 多设备同步

插件不另建云服务，也不要求单独登录账号。只要 Obsidian Sync、iCloud 云盘、坚果云或其他文件同步方案同步了整个库，并包含 `.obsidian` 配置文件夹，插件数据就会按照该服务的设置随库同步。请在各设备启用配置文件夹同步，并尽量避免在同步冲突尚未解决时由多台设备同时修改统计数据。`Study Time Statistics Backups/` 是普通库文件，也可能随整库同步。

## 开发与测试

```bash
npm install
npm test
npm run build
```

生产构建会生成 `main.js`。GitHub Release 必须附带 `main.js`、`manifest.json` 和 `styles.css`，并且标签必须与 `manifest.json` 中的版本号完全一致。

- 清单支持桌面端与移动端；后台焦点行为会因操作系统而异
