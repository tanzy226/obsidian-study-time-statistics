# Release roadmap / 发布路线

Future releases are developed in advance but are published only after their scheduled review date. Dates use Asia/Shanghai time.

未来版本可以提前开发，但只会在预定日期完成审核后发布。日期采用北京时间。

| Version | Planned release | Focus |
| --- | --- | --- |
| 2.2.0 | 2026-10-14 | Data health, safe repair, rename migration |
| 2.3.0 | 2026-11-11 | Filters, period comparison, session drill-down |
| 2.4.0 | 2026-12-16 | Attention map and study paths |
| 2.5.0 | 2027-01-27 | Tracking precision and mobile layout |
| 2.6.0 | 2027-03-10 | Privacy-first reports and export |
| 3.0.0 | 2027-06-16 | Local event engine and deterministic snapshot merge |

Every release remains subject to build, test, privacy, security, and release-asset verification. A failed review delays publication rather than shipping a known-bad build.

每个版本都必须通过构建、测试、隐私、安全和发布资产校验；检查失败时会延期，不会带着已知问题发布。
