# Release roadmap / 发布路线

See [GitHub Releases](https://github.com/tanzy226/obsidian-study-time-statistics/releases) for the current public version. [3.0.1](.github/release-notes/3.0.1.md) focuses on protecting saved data during merge, restore, and correction. Future updates are guided by feedback; no dates are promised.

当前公开版本见 [GitHub Releases](https://github.com/tanzy226/obsidian-study-time-statistics/releases)。[3.0.1](.github/release-notes/3.0.1.md) 优先保护合并、恢复和修正操作中的已有数据。后续版本会参考用户反馈，不预先承诺发布日期。

Every release requires build, test, privacy, security, CI, and release-asset verification. A failed review delays publication rather than shipping a known-bad build.

每个版本都须通过构建、测试、隐私、安全、CI 和发布资产校验；检查失败时会延期，不会带着已知问题发布。
