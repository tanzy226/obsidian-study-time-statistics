# Release roadmap / 发布路线

The current public release is **2.6.0**. We review the next version each week and publish it when it passes the release checks; there is no fixed waiting period or guaranteed release date. Development branches are not public releases.

目前公开版为 **2.6.0**。我们每周检查下一个版本，完成审核后即可发布；不设固定等待天数，也不承诺具体发布日期。开发分支不等于公开版本。

| Next version | Focus / 重点 |
| --- | --- |
| 3.0.0 | Local event engine and deterministic snapshot merge / 本地事件引擎与可确定性合并的数据快照 |

Each release still requires build, test, privacy, security, CI, and release-asset verification. A failed review delays publication rather than shipping a known-bad build. We release one version at a time, in order.

每个版本仍须通过构建、测试、隐私、安全、CI 和发布资产校验；不合格就延期，不会带着已知问题发布。版本按顺序逐个发布。
